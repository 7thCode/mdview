MDView

編集モードと参照モードを切り替えられる Markdown エディタ

macOS Apple Silicon (arm64) .dmg をダウンロード
Windows 64bit (x64) .exe をダウンロード
Linux AppImage / 64bit (x64) .AppImage をダウンロード

過去のリリース一覧は Releases から確認できます。

主な機能

  • 編集モード(CodeMirror)と参照モード(GFM レンダリング)の切り替え
  • Open / Save / Save As、Undo / Redo、Cut / Copy / Paste、検索・置換、ドラッグ&ドロップ、最近開いたファイル
