MDView へようこそ

書いたものは、すぐ読める。

  • 編集モードで書く
  • 参照モードで読む
  • 次のアイデアを書く
const mode = toggle('edit', 'view');

画面イメージです。ボタンで切り替えを試せます。

Features

必要なものだけ、きちんと。

テキストエディタとして当たり前の操作を押さえたうえで、Markdown を書く・読むことに絞りました。

⇄

ワンキーのモード切替

編集と参照を Ctrl/⌘+E で往復。編集画面は保持されるので、戻ってもカーソルと Undo 履歴はそのまま。

✎

快適な編集

CodeMirror 6 による Markdown ハイライト、Undo / Redo、検索・置換、日本語入力にも対応。

▦

テンプレートツールバー

見出し・太字・リンク・表など16種類のMarkdown要素をワンクリックで挿入。選択中のテキストはそのままテンプレートに反映され、CSVを選択すれば表に変換されます。

❏

きれいな参照表示

GitHub Flavored Markdown の表・タスクリスト、コードブロックのシンタックスハイライトを美しくレンダリング。

⚡

軽量ネイティブ

Tauri 製。インストーラは Windows 約2MB、macOS 約5MB。OS のネイティブメニューとショートカットで操作できます。

☾

ライト / ダーク自動追従

OS の外観設定に合わせて、エディタもプレビューも配色が切り替わります。

⛨

安心のファイル操作

ドラッグ&ドロップで開く、最近開いたファイル、未保存の変更は閉じる前に確認。改行コード(CRLF)も維持します。

Download

今すぐ使う。

最新版 v0.2.0 — お使いの OS に合わせてダウンロードしてください。

macOSUniversal(Apple Silicon / Intel) .dmg をダウンロード
Windows64bit (x64) .exe をダウンロード
Linux64bit (x64) .AppImage をダウンロード Debian / Ubuntu 向け .deb

現在のビルドはコード署名・公証を行っていないため、初回起動時に OS の警告が表示されます。以下の手順で起動できます(ダウンロード元が本ページ / GitHub Releases であることを確認してください)。

macOS の場合

「“MDView”は開けません」「開発元を検証できません」などと表示されたとき。

方法 1: システム設定から許可(macOS 15 Sequoia 以降はこちら)

  1. .dmg を開き、MDView を「アプリケーション」フォルダへドラッグします。
  2. MDView を一度開き、警告ダイアログを「完了」で閉じます。
  3. 「システム設定 → プライバシーとセキュリティ」を開き、下部の「セキュリティ」欄にある「“MDView”は開くのをブロックされました」の「このまま開く」をクリックします。
  4. パスワードまたは Touch ID で認証し、確認ダイアログで「開く」を選びます。以降は通常どおり起動できます。

方法 2: 右クリックで開く(macOS 14 Sonoma 以前)

  1. 「アプリケーション」フォルダで MDView を control を押しながらクリック(または右クリック)します。
  2. メニューの「開く」を選び、確認ダイアログでもう一度「開く」を選びます。

方法 3: ターミナルで隔離属性を削除

「壊れているため開けません」と表示される場合はこちらです。

xattr -dr com.apple.quarantine /Applications/MDView.app

Windows の場合

「Windows によって PC が保護されました」(Microsoft Defender SmartScreen)と表示されたとき。

インストーラ(.exe)の実行

  1. ダウンロードした .exe をダブルクリックします。
  2. 警告画面の本文中にある「詳細情報」をクリックします。
  3. 表示された「実行」ボタンをクリックします。
  4. ユーザーアカウント制御(UAC)が出たら「はい」を選び、インストーラの指示に従います。

ブラウザでブロックされた場合

  1. Edge / Chrome のダウンロード一覧で該当ファイルの「…」→「保持する」を選びます。
  2. 必要に応じて「詳細を表示」→「保持する」を選びます。

それでも起動しない場合

  1. .exe を右クリック →「プロパティ」を開きます。
  2. 「全般」タブ下部の「セキュリティ」欄で「許可する」にチェックを入れ、「OK」を押します。
  3. もう一度 .exe を実行します。
